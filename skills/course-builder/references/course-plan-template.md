# Course draft template

Use this structure for Phase 3. Fill it with specifics, not generalities.

```markdown
# <Course title>

## Passport
- **Promise:** <Who> comes with the question "<question in their own words>" and after the course can <concrete, measurable result>.
- **Client and goal:** <product / staff training / lead magnet / …>
- **Language:** <…>
- **Entry level:** <…>
- **Total volume:** <N modules, M lessons, ~X hours>
- **Formats:** <animated video / collage / PDF / Word / …>
- **Design direction (unslop):** Character: <2–3 words>; World: <world of the topic>; Accent: <color>

## Module 1. <Title — a result, not a topic>
Module goal: <what the learner can do after it>

### Lesson 1.1. <Title>
- **After this lesson the learner can:** <action verb + object>
- **Key ideas:** 1) … 2) … 3) …
- **Practice:** <a task that can be done and checked>
- **Format:** <5-min animation + PDF checklist>
- **Duration:** <min>
- **Sources:** <from the research>

### Lesson 1.2. …

## Module 2. …

## Final assessment
<quiz / project / case — how we check the course promise>

## Production
| Material | Count | Volume | Tool |
|---|---|---|---|
| Animated videos | 8 | ~40 min | Remotion + ElevenLabs |
| PDF summaries | 8 | ~30 pages | pdf skill |

## Open questions for the client
- …
```

Rules:
- A module title is a result ("Build your first budget"), not a topic ("Budgeting basics").
- "The learner can …" uses action verbs: build, calculate, choose, explain, set up. Not "know" or "understand": those can't be checked.
- Lesson durations must add up to the volume from question 2.
