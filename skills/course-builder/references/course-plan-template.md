# Шаблон черновика курса

Используй эту структуру для Фазы 3. Заполняй конкретикой, без общих слов.

```markdown
# <Название курса>

## Паспорт
- **Обещание:** <Кто> приходит с вопросом «<вопрос в его словах>» и после курса может <конкретный измеримый результат>.
- **Заказчик и цель:** <продукт / обучение сотрудников / лид-магнит / …>
- **Язык:** <…>
- **Уровень входа:** <…>
- **Общий объём:** <N модулей, M уроков, ~X часов>
- **Форматы:** <видео-анимация / коллаж / PDF / Word / …>
- **Дизайн-направление (unslop):** Character: <2–3 слова>; World: <мир темы>; Accent: <цвет>

## Модуль 1. <Название — результат, а не тема>
Цель модуля: <что ученик умеет после>

### Урок 1.1. <Название>
- **После урока ученик может:** <глагол действия + объект>
- **Ключевые идеи:** 1) … 2) … 3) …
- **Практика:** <задание, которое можно выполнить и проверить>
- **Формат:** <анимация 5 мин + PDF-чеклист>
- **Длительность:** <мин>
- **Источники:** <из исследования>

### Урок 1.2. …

## Модуль 2. …

## Итоговая проверка
<тест / проект / кейс — как проверяем обещание курса>

## Производство
| Материал | Кол-во | Объём | Инструмент |
|---|---|---|---|
| Анимированные ролики | 8 | ~40 мин | Remotion + ElevenLabs |
| PDF-конспекты | 8 | ~30 стр | skill pdf |

## Открытые вопросы к заказчику
- …
```

Правила:
- Название модуля — результат («Составить первый бюджет»), а не тема («Основы бюджетирования»).
- «Ученик может …» — глаголы действия: составить, рассчитать, выбрать, объяснить, настроить. Не «знать» и «понимать» — их нельзя проверить.
- Сумма длительностей должна сходиться с объёмом из вопроса 2.
